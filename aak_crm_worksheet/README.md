# CRM Stage Worksheet (Odoo 18)

This addon lets you link a **Worksheet Template** (`worksheet.template`) to any **CRM Stage**.
When a lead/opportunity moves into such a stage, the module opens the worksheet to fill.

## Install
1. Drop `aak_crm_worksheet` into your addons path.
2. Update Apps list and install **CRM Stage Worksheet**.

## Use
- Go to **CRM ‣ Configuration ‣ Stages**, pick a stage and set a **Worksheet Template**.
- On a lead moved into that stage, the worksheet will popup automatically.
