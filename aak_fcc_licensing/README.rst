AAK FCC Licensing v18E
======================

This module provides functionality to manage FCC licensing requirements for sales teams.

Features
========
- Track FCC licensing required for each sales team.
- Upload FCC license files and attach them to Sale Orders.
- Chatter integration to log uploaded licenses.
- Easy access via Sales → Configuration → FCC Licensing.

Configuration
=============
* No additional configuration required.

Odoo Modules Dependencies
=========================
* sale_management (Sales)
* crm
