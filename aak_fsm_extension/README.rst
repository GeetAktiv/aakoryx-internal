Field Service Extension
=======================

This module extends the Field Service Management (FSM) by adding extra features:
- Work Ticket ID (auto-generated)
- Service Type (e.g., Security, 2-Way Radio)
- Bill of Materials (BOM) assignment
- Technical Requirements and FCC License details
- Vehicle and reference document handling
- Link products from related sale orders to tasks
- View linked products directly from task form

Dependencies:
-------------
* industry_fsm (Field Service Management)
* mrp (Manufacturing)
* sale
* industry_fsm_stock

Installation:
=============
Simply install this module after the `industry_fsm`, `mrp`, `sale`, and `industry_fsm_stock` modules.
