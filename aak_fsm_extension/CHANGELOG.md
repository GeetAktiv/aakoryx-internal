# Changelog

## [18.0.1.0.0] - 2025-10-14
- Initial release of AAK FSM Extension module.
- Added Work Ticket ID auto-numbering.
- Added new fields for service type, technical requirements, and vehicle assignments.
- Created project task stages for FSM project type.

## [18.0.1.1.0] - 2025-10-14
- Added `product_ids` field in project tasks to link products from sale order lines.
- Added `sol_products_count` computed field to show total products linked to task.
- Added action to view linked products from project task form.
- Updated task form view to replace material button with products button.
- Updated module dependencies to include `sale` and `industry_fsm_stock`.

## [18.0.1.2.0] - 2025-10-16
- Added Vehicle smart button to the Project Task form view.
