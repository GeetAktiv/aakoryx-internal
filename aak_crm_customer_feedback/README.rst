AAK CRM Customer Feedback
==========================

Overview
--------
This module automatically sends a customer feedback survey after the completion of tower installation tasks. It triggers an email with a survey link once the related project task is marked as done.

Features
--------
- Automatically sends feedback survey after a project task is marked as done.
- Schedules daily activities for newly created CRM leads.
- Includes questions on service satisfaction, installation quality, safety, timeliness, and additional services.
- New survey questions include:
  - What could we do to improve your overall experience?
  - What additional solutions would you like more information about?
    - Alarm Systems
    - Video Surveillance
    - Access Control
    - Fire Detection
    - Monitoring Services

Installation
------------
1. Copy the module folder to the `addons` directory of your Odoo instance.
2. Restart the Odoo server.
3. Install the module from the Odoo Apps menu.

Dependencies
------------
- **crm**
- **mail**
- **survey**
- **project**

No additional configuration is required.
